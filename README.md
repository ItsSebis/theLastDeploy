# The Last Deploy

A browser text-adventure: a timed scramble through a dying client repo, then a
sprint/night survival loop with resource management and random incidents.
Reskinned around software agency culture.

Design and technical docs live in [`docs/`](docs/00-start-here.md).

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check + production build
npm run lint     # lint
```
